## 1. Описание идеи решения и обоснование выбора структуры данных
Все задачи реализованы на языке Java с использованием стандартного класса `Scanner` для чтения данных из потока ввода. 
В качестве основной структуры данных используется одномерный массив (для задач 31 и 35), так как он обеспечивает доступ к элементам за O(1).
Для задач 25, 26, 27, 36 массив не требуется, так как вычисления производятся при чтении каждого числа, что экономит память.

## 2. Анализ асимптотики (время и память)
- **Задачи 25, 26, 27, 36:** Время O(n) — один проход по всем элементам. Память O(1) — не требуется хранить весь массив.
- **Задача 31:** Время O(n) — один проход по элементам. Память O(n) — требуется сохранить первый массив для перемножения.
- **Задача 35:** Время O(n + q) — O(n) на построение префиксных сумм и O(1) на каждый из q запросов. Память O(n) — для хранения массива префиксных сумм.

## 3. Примеры ручных тестов
Для каждой задачи написаны unit-тесты (JUnit 5). 
Пример ручного теста для задачи 25: 
- Вход: `5 \n 1 2 3 4 5`
- Ожидаемый выход: `15`
- Объяснение: сумма элементов 1+2+3+4+5 = 15. Тест проверяет базовый функционал и отсутствие переполнения.
