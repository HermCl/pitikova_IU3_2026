# Задача 27. Сумма квадратов

## Асимптотика
- **Время:** O(n) — один цикл прохода по массиву.
- **Память:** O(1) — дополнительная память не зависит от размера массива.

## Идея решения
Для каждого считанного числа вычисляется его квадрат (умножение на само себя), который затем прибавляется к общей сумме. 
*Важно:* переменная для суммы имеет тип `long`, так как квадрат числа и последующая сумма могут легко выйти за пределы типа `int`.
