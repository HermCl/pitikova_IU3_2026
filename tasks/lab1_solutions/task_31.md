# Задача 31. Скалярное произведение

## Асимптотика
- **Время:** O(n) — требуется один проход по элементам векторов.
- **Память:** O(n) — требуется сохранить первый массив (вектор `a`), чтобы при считывании второго массива (вектор `b`) перемножить их поэлементно и сложить.

## Идея решения
Сначала считывается первый массив в память. Затем в цикле считываются элементы второго массива. На каждом шаге вычисляется произведение `a[i] * b[i]`, которое прибавляется к общему результату `dot`. 
*Важно:* используется тип `long` для предотвращения переполнения.
