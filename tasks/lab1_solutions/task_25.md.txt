# Задача 25. Сумма элементов

## Асимптотика
- **Время:** O(n) —  проходим по массиву ровно один раз, выполняя сложение для каждого элемента.
- **Память:** O(1) — не нужно хранить весь массив, так как мы считываем числа и сразу добавляем их в аккумулятор.

## Идея решения
Считываем количество элементов `n`. Затем в цикле считываем каждое число и прибавляем к переменной `sum`. 
*Важно:* используется тип `long`, чтобы избежать переполнения при больших значениях (так как сумма может превысить максимальное значение `int`).
