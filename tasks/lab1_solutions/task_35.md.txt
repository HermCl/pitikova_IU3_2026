# Задача 35. Префиксные суммы

## Асимптотика
- **Время:** O(n + q) — O(n) на построение массива префиксных сумм и O(1) на обработку каждого из `q` запросов.
- **Память:** O(n) — требуется дополнительный массив размера n + 1 для хранения префиксных сумм.

## Идея решения
Создается массив `prefix`, где `prefix[i]` — сумма первых `i` элементов исходного массива (с индексом от 0 до i-1). 
Сумма элементов на отрезке от `l` до `r` включительно вычисляется за одно действие по формуле: `prefix[r + 1] - prefix[l]`.
